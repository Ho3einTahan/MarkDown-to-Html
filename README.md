# MarkDown To Html
Easily convert Markdown files to HTML with this simple tool.

## Clone the Repository
Run the following command to clone the repository:
```bash
git clone https://github.com/Ho3einTahan/MarkDown-to-Html.git
```

1. Make sure to create a mark.md file with your Markdown content.
2. Use the following command to convert the file to HTML.

## Example
```bash
node app.js mark.md -o mark.html
```
